# Daymark — To-Do List Management System

A responsive, browser-based task manager built with HTML, CSS, and vanilla JavaScript.

## Features
- Create, edit, and delete tasks
- Mark tasks as completed
- Task descriptions, priorities, and due dates
- Search tasks and filter by priority
- Views for all tasks, today, upcoming, and completed
- Dashboard statistics and completion progress
- Sort by recently added, due date, or priority
- Browser `localStorage` persistence
- Responsive desktop and mobile layouts

## Run locally
No installation or build step is required. Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Data note
Tasks are saved in the current browser on the current device. This version does not use accounts, cloud sync, or a remote database.

## Publish with VS Code
1. Open this folder in VS Code.
2. Select **Source Control** from the left sidebar.
3. If prompted, choose **Initialize Repository**.
4. Stage files using the `+` beside **Changes**, or use **Stage All Changes**.
5. Enter a commit message such as `Initial commit: Daymark task manager`, then select **Commit**.
6. Select **Publish to GitHub** (or **Publish Branch**) and sign in when prompted.
7. Choose a public or private repository. Check the repository visibility before publishing.

You do not need to type `git push` in the terminal. VS Code performs the Git operations through its interface.
